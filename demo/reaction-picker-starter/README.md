# Reaction picker — live starter

> Premature, unvalidated artifact: the contents of this starter have not been approved. Use the [presentation map](../../.scratch/wayfinder-meetup/map.md) to settle the intended scope and preparation before treating it as the on-stage starting point.

This is the prepared starting point, not the finished app. It contains Vite, React, TypeScript, pinned `gif-picker-react`, bundled Emoji Mart data, and a minimal landing page. The adjacent POC is the completed reference.

From the presentation root, run `pnpm demo:install`, then `pnpm demo:starter`. Open http://127.0.0.1:5175. The POC uses port 5174, so both can stay open.

Launch your chosen harness with **this directory as its working directory**, then follow [the demo prompts](../../docs/demo/runbook.md). Prepare `.env.local` from `.env.example` before the event. Keep keys out of visible prompts and command output. The starter deliberately has no GIF component yet; the agent will use the prepared configuration when implementing it.

Use a separate fresh copy if you need another starting point. Do not reset or overwrite the POC to restart the demo. Setup for the chosen tracker belongs in this project; see Matt's `/setup-matt-pocock-skills` workflow.

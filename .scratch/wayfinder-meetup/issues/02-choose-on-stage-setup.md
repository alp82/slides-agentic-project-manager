## Question

Which harness and issue tracker should the presenter use on stage so the audience can see questions, dependencies, and saved context clearly? Both Claude Code and Codex are acceptable. Decide whether one harness is sufficient and whether local Markdown or a tracker UI best serves this audience. Name setup prerequisites to complete before the event, without provisioning them during this decision.

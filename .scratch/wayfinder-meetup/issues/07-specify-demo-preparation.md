## Question

Given the agreed story, demo journey, setup, scope, and visual approach, what must the later build handoff produce to make the deck and demo materials complete? Specify the prebuilt POC, starter contents, prepared checkpoints, how prompts will be derived from building the POC, and the fallback transitions. Define observable completion criteria without rehearsing the presentation or guaranteeing agent run times.

Preserve wayfinder's separate charting/work sessions and one non-research decision per work session. If the on-stage effort will include execution, specify an explicit override for that demo effort; it does not authorize executing this presentation map during charting.

## Assets

The [premature runbook](../../../docs/demo/runbook.md) is an unvalidated proposal. Its prompts must be reconsidered against the resolved decisions and what is learned when the agreed POC is built. This ticket records the preparation specification, not finished apps, slides, or a rehearsed script.

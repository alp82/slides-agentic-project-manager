# Define the reaction-picker POC scope

Type: grilling
Label: wayfinder:grilling
Status: open
Assignee: unassigned
Parent: [Make the wayfinder meetup presentation](../map.md)
Blocked by: 01

## Question

What is the smallest complete reaction-picker POC that supports the chosen demo journey, and what belongs in the prepared starter? Agree the essential user flow and feature boundaries, then select a bounded live change if the journey includes execution. Search, GIF/emoji choice, large preview, and copy are proposals, not a locked specification. The existing recent-emoji implementation does not make it a requirement.

## Context

Use the resolved teaching journey to judge scope. The user wants the whole POC prebuilt later so the actual experience can inform prompts. The premature [POC](../../../demo/reaction-picker-prototype/README.md) may inform the discussion but must not silently decide it.
